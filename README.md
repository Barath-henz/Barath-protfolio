# Barath A — Engineering Portfolio

A responsive React + Vite portfolio for an aspiring DevOps and Network Engineer. It presents current skills and learning goals honestly and features the SOC Monitoring Dashboard project.

## Run locally

Requirements: Node.js 18 or newer and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

To create and preview a production build:

```bash
npm run build
npm run preview
```

## Personalize before publishing

- Add your portrait as `public/barath.jpg` to show it in the profile card. Until then, the initials placeholder remains visible.
- Add your resume PDF as `public/Barath-A-Resume.pdf`; the hero's Download Resume button downloads this file.
- Add your email address when ready.
- Review the currently learning list and project details as your experience develops.

The featured SOC project's technologies are based on its repository documentation: Python/Flask, Flask-SocketIO, SQLite, HTML/CSS/JavaScript, Chart.js, and Docker Compose. The dashboard graphic on the portfolio is an illustrative preview, not a screenshot of the deployed application.
